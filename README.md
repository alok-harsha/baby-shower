# Baby Shower Invitation

Interactive envelope invitation for Alok & Harsha's baby shower,
Saturday 24 October 2026, Blue Zenzer, Playgolf Northwick Park, Harrow.

Live page: https://alok-harsha.github.io/baby-shower/

- `index.html` — the whole invitation. Self-contained: every image is
  embedded, so the file works on its own with no other assets.
- `preview.jpg` — the card WhatsApp and iMessage show when the link is shared.
- `robots.txt` — asks search engines not to index the page.
